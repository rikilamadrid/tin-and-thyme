## Goal

A reviewed ticket shows "Ready to deliver". The human can open a delivery drawer, inspect everything, and run the operations step by step, approving the exact merge. Partial results stay visible across reconnects.

## Changes

- A "Ready to deliver" entry for tickets whose engine state is `done` with a review PASS.
- The drawer shows: repo, base, branch, the exact head and the reviewed head, the diff summary and file list, review evidence, the local verification evidence, the PR, checks and mergeability, and each step's status.
- Commands carry a request id and get a reply event. Delivery-changing commands refuse WebSocket clients without a browser Origin.
- An approval tied to `{head, base, tree}` is shown as stale when either moves.
- With no checks, merging needs an explicit acknowledgement.
- The snapshot includes delivery state, so a reconnect restores it.

## Verification

- Tests:
  - a reconnect restores the delivery state;
  - a stale approval can't be used;
  - partial success renders per step;
  - a client without an Origin is refused;
  - acknowledgement is required when there are no checks.
- A headless walkthrough against fakes.
- `pnpm typecheck` and `pnpm build` pass.
