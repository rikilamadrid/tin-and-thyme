## Goal

A "Summarise" button in an idle agent's drawer asks the agent for a short
summary of its work, then shows it with a Copy button.

## Changes

- Server helper: send a marked prompt to an idle agent and await its Stop, with
  a timeout and no automatic resend. 03.2 and 04.2 reuse it.
- Summary prompt → the agent writes `.jsmhq-summary.md` (excluded from git).
  The server reads it after Stop and publishes it on the snapshot.
- Drawer: Summarise (disabled with a reason unless idle), the summary text, its
  time, and Copy.
