# Hide a feature from the kitchen's work surfaces

## Status

In Progress

## Parent Feature

`06-coordinator-attention-state.md`

## Blocked by

- `06.1` — hiding is matched by ticket and session identity, and the kitchen's current worker-to-ticket attribution is wrong. Today a live 10.x worker is shown as 02.1, so hiding Feature 02 by its key would hide unrelated live work.

## Goal

The human can hide a whole Feature from the normal work surfaces while working on others, without deleting, cancelling, completing or releasing anything. The first case is Feature 02.

## Context

- Human decision, 2026-11-12. This is a visibility decision only. Feature 02's commits, branch, worktree, claim, gate and verification history stay exactly as they are. 07.1 is unchanged.
- Reuse what exists: board and feature grouping (`applyBoard` and `featureTitle`, `server/pathfinder.ts` ~L779-800 at `7b3eda3`), gate action items (~L880-925), the WebSocket snapshot and reconnect (`src/data/ws/wsSource.ts`), and the Settings modal (`src/ui/settings/`).
- Relevant area: `server/pathfinder.ts`, `src/data/types.ts`, `src/ui/hud/CrewPanel.tsx`

## Changes

- Minimal (human, 2026-11-12): suppress Feature 02's visual records and alerts only. Use a small server-side suppression for the feature key `02`, applied to the snapshot, so refreshes and reconnects agree. There is no general hidden-features system.
- Hidden features don't appear in: Feature tabs, Boards, the wall board, ticket cards, transporter queues and other pending-work displays; Action items, attention counts, notifications and sounds. Their gates stay open and unresolved, only suppressed from display.
- Finished sessions of a hidden Feature's tickets drop out of current crew and activity displays, with their history kept. A live session is never hidden. A robot's unrelated current session is never hidden because of a previous Feature 02 session. Matching is by ticket and session identity, using 06.1's attribution, never by name or character.
- Hidden is shown as distinct from Cancelled and Complete wherever it is shown.

## Verification

- Tests:
  - hiding Feature 02 removes its tickets, gate and action item from the snapshot surfaces and attention counts, and the engine state and gate stay unchanged;
  - a live session is never hidden;
  - an unrelated session of the same character stays visible;
  - the state is the same after a reconnect and after a server restart;
  - Feature 02 is absent from tabs, boards, cards, floor labels, Action items, counts and sounds, including after a refresh.
- `pnpm typecheck` and `pnpm build` pass.

## Out of Scope

- Lifecycle changes, cancelling, releasing claims, and deleting history.
